# Troop 182 Court of Honor Script Creator
Created by Matthew Glasser

## To run:
Open the [spreadsheet](https://docs.google.com/spreadsheets/d/1UzGgYpoI6UZwFRvD6rZrSaZZP8PFTFlCGmuBa_GgW1w/edit?gid=1786546864#gid=1786546864)
Enter information on all the pages
Check the "create new document" checkbox on the Instructions page, or enter a link for the Google Doc that it should edit in the box below
Click "Prepare > Write script" in the menu bar. You will need to give the app permissions (click advanced & run anyway because the app isn't verified)
The document will be generated on your Google account, and the link will be in the red box on the "Instructions" sheet

If you're not on a Google account, I'm not sure if it will work.

Source Code can be found in this repo in `Code.js`.
